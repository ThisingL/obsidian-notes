>翻开一本数学教材，大家总会看到诸如上面的这些词，有人戏称，一本数学书无非是给几条公理，下几个定义，证几个定理，推十几个推论，再配几十道课后习题。

从逻辑学的观点来说，引理、命题、定理和推论之间并没有什么不同

它们都是有待验证的一些论述。然而我们使用这些术语是为了说明不同论述在重要性和困难程度上的不同。

引理很容易被证明，它有助于进一步证明其他的命题和定理，但是单独一个引理通常不会特别引起人们的关注。

单独一个命题是值得研究的，定理比命题更重要。定理是对研究对象权威性的描述，而且证明一个定理需要比证明一个命题或者引理付出更多的努力。

推论是能够从目前已经被证明的命题或者定理中立即推导出的结论。

| 关键词            | 关键点                     | 解释                                                |
| :------------- | :---------------------- | ------------------------------------------------- |
| 公理 axiom       | 不加证明的起点（不证自明）           | 它不是“真理”，是“理论启点和基本假设”。改公理 = 换世界（欧氏 / 非欧几何、要不要选择公理） |
| 定义 definition  | 给概念或符号起名字，规定含义          | 没有真假，只是约定记号，只有好不好用；要检查 well-defined（不依赖任意选择的表示）   |
| 命题 proposition | 真的、值得陈述，但核心度低于定理        | 常作承前启后，或顺手得到的结果                                   |
| 定理 theorem     | 非常重要，值得专门**命名**，以及反复应用的 | 是一条链的目标；条件一句都不能省                                  |
| 引理 lemma       | 为了证别的东西而先证的工具           | 单独看往往很技术、不漂亮；价值全在于“后面要用它”                         |
| 推论 corollary   | 几乎不用证，由前面直接得到           | 典型形式是特例、换表述、对偶；紧跟在它所依赖的定理后面                       |
