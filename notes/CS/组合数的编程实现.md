如果需要我们计算组合数：

$$
C_{n}^{k} = \binom{n}{k} = \frac{n!}{k!(n - k)!}
$$

如果直接用数学公式的算法，那么在编程的世界里是算不出来的，因为会 long long 溢出，因此我们需要更优雅的编程实现。

对于

$$
\binom{n}{k} = \frac{n!}{k!(n - k)!}
$$

把 k 替换成 k - 1:

$$
\binom{n}{k-1} = \frac{n!}{(k-1)!(n - k+1)!} = \frac{k \times n!}{k(k-1)!(n - k)!(n-k+1)} = \frac{k}{(n-k+1)} \times \binom{n}{k}
$$

可得递推式：

$$
\binom{n}{k} = \frac{\binom{n}{k-1} \times (n-k+1)}{k}
$$

由于 $\binom{n}{k}$ 是整数，所以右边等式一定可以整除。所以其实这个等式的写法是:

$$
C_{n}^{k} = C_{n}^{k-1} \times \frac{n-k+1}{k}
$$

> [!NOTE]
> 也可以这样理解，由于任意连续 $k$ 个数中必然有 $k$ 的倍数，所以上述计算过程均为整除，不会产生小数。

代码实现：

```c++
long long comb(int n, int k) {
	k = min(k, n - k);  // 减少计算次数
	long long res = 1;
	for (int i = 1; i <= k; i ++) {
		res = res * (n - i + 1) / i;
	}
	return res;
}
```
